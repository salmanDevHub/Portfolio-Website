# Salman Shahid — Portfolio Website

This repository contains the source code for Salman Shahid's personal portfolio website. It presents my software engineering background, skills, experience, and selected work through an interactive web experience.

## About

I am a Software Engineering student at COMSATS University Islamabad with hands-on experience in Laravel, Flutter, React.js, PHP, JavaScript, Python, and MySQL. I build responsive web and mobile applications with a focus on practical, user-friendly solutions.

## Features

- Interactive 3D character and WebGL scene
- Smooth GSAP-powered scrolling and animations
- Responsive portfolio sections for skills, experience, work, and contact details
- Custom loading experience with progress feedback

## Getting Started

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

Create a production build:

```bash
npm run build
```

Check the code quality:

```bash
npm run lint
```

## Tech Stack

React • TypeScript • GSAP • Three.js • WebGL • HTML • CSS • JavaScript
